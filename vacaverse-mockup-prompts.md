## Tips for Best Results:

1. **Specify the AI tool**: Some tools work better with certain phrase structures
2. **Request style references**: Add "in the style of [Airbnb/Notion/modern SaaS app]"
3. **Iterate**: Generate multiple versions and combine best elements
4. **Add context**: Include "clean", "modern", "professional" or "friendly", "playful"
5. **Specify details**: Request specific UI elements like "rounded corners 12px" or "soft drop shadow"
6. **Reference real apps**: "Similar to Asana task cards" or "Like Google Calendar grid"
